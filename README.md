A complete, production-ready React landing page with smooth scroll animations, responsive design, and modern UI components. Built with **Vite**, **React 18**, **Tailwind CSS**, and **Lucide Icons**.

## ✨ Features

✅ **Sticky Navigation** - Fixed navbar with scroll-based styling  
✅ **Hero Section** - Full-screen with parallax background effect  
✅ **Scroll Animations** - Image rotation/scale on 150px scroll threshold  
✅ **Responsive Design** - Mobile hamburger menu, mobile-first approach  
✅ **Reusable Components** - CTAButton, NavLink, FooterLink, SocialButton  
✅ **Custom Animations** - FadeInUp, SlideIn, Float, Glow effects  
✅ **Dark Footer** - Multi-column layout with contact info and social links  
✅ **Production Ready** - Optimized, well-documented, copy-paste ready  



### 1️⃣ Create Vite Project 
```bash
npm create vite@latest my-project -- --template react
cd my-project
npm install
npm install -D tailwindcss postcss autoprefixer
```
